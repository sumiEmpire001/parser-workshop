# Embedded C++ companion
The Python parser is preserved. `cpp/core.hpp` is a bounded C++11 recursive-descent calculator for Arduino/ESP32 serial command expressions. Supports +,-,*,/, unary +/- and parentheses, with 128-character maximum, recursion depth 24, syntax validation, finite-result enforcement and division-by-zero rejection. Output is changed only on success; false means no valid command should be executed. Uses `strtod` and C++ double; precision and floating parsing vary on AVR (Uno often has 32-bit double). Not for billing, safety setpoints or untrusted real-time motor commands without an independent range checker, watchdog and emergency stop.
Run: `cmake -S . -B build && cmake --build build && ctest --test-dir build --output-on-failure`. Python regression: `python -m unittest discover -s tests -v`. No physical hardware verification or board compilation claimed.
